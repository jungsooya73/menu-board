# ☕ 브릿지 커피 디지털 메뉴판

손님이 테이블의 QR 코드를 찍으면 휴대폰으로 보는 **브릿지 커피**의 디지털 메뉴판입니다.

> 매일 직접 볶는 스페셜티 커피 · 광주 북구 비엔날레

## 주요 기능

- **종류별 메뉴**: 커피, 논커피, 디저트로 나눠서 메뉴 이름, 가격, 한 줄 설명을 보여줍니다
- **종류 바로가기 버튼**: 화면 위에 늘 붙어 있고, 지금 보고 있는 종류에 색이 칠해집니다
- **대표 메뉴 표시**: 아인슈페너, 흑임자 라떼에 "대표" 표시가 붙습니다
- **영업시간과 전화 걸기**: 버튼을 누르면 가게로 바로 전화가 걸립니다
- **휴대폰에 맞춘 화면**: 가로 390px 기준이고, 접는 폰(280px)이나 가로 화면에서도 깨지지 않습니다

## 디자인

| 항목 | 내용 |
|---|---|
| 스타일 | 글래스모피즘: 반투명 카드, 부드러운 그림자, 둥근 모서리 |
| 대표 색상 | 짙은 갈색 `#4A3728` (배경), 크림색 `#F5EFE6` (카드·글자) |
| 글꼴 | 고운 돋움 (없으면 맑은 고딕) |
| 분위기 | 조용한, 담백한, 과하지 않은 |

## 파일 구성

```
디지털메뉴보드/
├── index.html        메뉴판 전체 (HTML, CSS, JavaScript가 이 파일 하나에 다 있어요)
├── qr.html           테이블에 붙일 QR 카드를 만드는 도구 (사장님용)
├── 메뉴판올리기.bat   더블클릭하면 메뉴판을 인터넷에 올려주는 프로그램
├── CLAUDE.md         AI 도우미(Claude)와 작업할 때 지키는 약속
├── README.md         지금 보고 있는 안내서
└── 자료/             기획 시트 사진
```

리액트 같은 도구 없이 **HTML, CSS, JavaScript만** 썼어요. 따로 설치할 것 없이 파일만 열면 바로 보입니다.

## 내 컴퓨터에서 보기

1. `index.html`을 마우스 오른쪽 버튼으로 눌러요
2. **연결 프로그램 → Google Chrome**을 골라요
3. 휴대폰 크기로 보려면 크롬에서 **F12**를 누른 뒤 **Ctrl + Shift + M**을 눌러요

## ✏️ 메뉴 고치기

메뉴 정보는 `index.html` **맨 위의 "📋 메뉴 정보 모음"** 한곳에 모여 있어요. 메뉴 하나는 이렇게 한 줄이에요.

```js
{ 이름: "아메리카노", 가격: "4,500원", 설명: "산미가 적은 고소한 원두" },
```

| 하고 싶은 일 | 방법 |
|---|---|
| 가격 고치기 | 따옴표 안의 숫자만 바꿔요 |
| 메뉴 추가 | 메뉴 한 줄을 복사해서 바로 아래에 붙여넣고 글자를 바꿔요 |
| 메뉴 빼기 | 그 메뉴 한 줄을 통째로 지워요 |
| 대표 표시 | 줄 끝 `}` 앞에 `, 대표: true`를 적어요 |
| 새 종류 만들기 | `[디저트]` 덩어리를 통째로 복사해서 붙여넣어요. 버튼도 저절로 생겨요 |

더 자세한 방법은 파일 안 안내 메모에 예시와 함께 적혀 있어요.

**메뉴판이 갑자기 안 나오면** 아래를 확인하세요.
- 따옴표(`"`)를 빠뜨리지 않았나요?
- 줄 끝 쉼표(`,`)를 빠뜨리지 않았나요?
- 괄호 `{ }` `[ ]`를 지우지 않았나요?

가게 이름, 영업시간, 전화번호, 색깔도 파일 안 **✏️ 표시**가 있는 곳에서 고칠 수 있어요.

## 🌐 인터넷에 올리기

`메뉴판올리기.bat`을 **더블클릭**하면 자동으로 올라가요.

1. 처음 한 번만 넷리파이(Netlify) 로그인 창이 열려요
2. `index.html` **하나만** 인터넷에 올라가요. 자료 폴더는 올라가지 않아요.
3. 테이블에 붙일 QR 코드 그림 `메뉴판QR.png`가 폴더에 생겨요

- **주소**: https://bridge-coffee-gwangju.netlify.app
- 메뉴를 고친 뒤 다시 실행해도 **주소와 QR은 그대로**예요
- 컴퓨터에 [Node.js](https://nodejs.org/ko)가 설치되어 있어야 해요

## 🔲 QR 카드 만들기

`qr.html`을 더블클릭하면 테이블에 붙일 QR 카드를 만들 수 있어요.

1. **인터넷 주소**, **가게 이름**(QR 위), **안내 문구**(QR 아래)를 적어요. 처음부터 메뉴판 주소가 적혀 있어요.
2. **[QR 코드 만들기]**를 눌러요
3. **[⬇️ 그림으로 저장]**을 누르면 `메뉴판QR_카드.png`로 저장돼요. 인쇄해도 선명한 큰 그림이에요.
4. **[🖨️ 인쇄하기]**를 누르면 카드만 A4 종이 가운데에 폭 12cm로 인쇄돼요

- **인터넷 없이도 돼요.** QR 계산 도구를 파일 안에 넣어 두었어요. 단, 인터넷이 없으면 글꼴이 고운 돋움 대신 맑은 고딕으로 나와요.
- 인쇄 크기는 파일 안 `✏️ 인쇄 크기` 메모가 있는 곳에서 바꿀 수 있어요.
- 손님에게 보이는 페이지가 아니에요. 메뉴판올리기는 `index.html`만 올려요.
- 붙이기 전에 꼭 휴대폰으로 찍어서 메뉴판이 열리는지 확인하세요.
